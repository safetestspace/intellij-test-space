# Test Space

JetBrains IDE plugin that makes Java, Python, and Rust test names readable.

Kotlin lets you write test method names with spaces using backticks.
Jest takes a string as the test name, like `test('should save an order', ...)`.
Both read better, so Test Space brings this readability to other languages, at least in the editor.

```text
should_save_an_order  →  should save an order
shouldSaveAnOrder     →  should save an order
```

Only test declarations change visually.
Source code, references, and test runner names stay unchanged.
Move the caret onto a name to edit the original identifier.

Requires IntelliJ IDEA, PyCharm, or RustRover 2024.3 or newer, with the corresponding language support enabled.

- Java: JUnit 3 (`TestCase`), JUnit 4, JUnit Jupiter, TestNG, and composed test annotations.
- Python: default pytest file/class/function naming and unittest `TestCase` subclasses, including async tests.
- Rust: `#[test]`, Tokio, async-std, Actix, rstest, and test-case attributes.

Custom pytest discovery patterns and Rust tests generated by macros or conditional attributes aren't supported yet.

Configure formatting in **Settings → Editor → Test Space** and styling in **Editor → Color Scheme → Test Space**.
Add preserved names (one per line) to keep their spelling during camelCase splitting; `TestNg` is included by default.
